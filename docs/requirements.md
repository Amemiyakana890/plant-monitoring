# 要件定義書

## 1. システム概要

植物の育成環境を専用センサーデバイス(ESP32)で取得し、スマートフォンアプリ「植物見守り」から確認できるIoTシステム。

## 2. システムの目的

- 植物の状態を見える化する
- 育成をサポートする
- センサーデータを記録する
- 植物の管理を分かりやすくする
- 普段は意識せず、必要な時だけ状態を知らせる

## 3. 利用者・利用シーン

### 利用者

| 利用者 | 内容 |
|---|---|
| 植物を育てる人 | 日常的な管理 |
| 初心者 | 育成サポート |

### 利用シーン

- 朝、植物の状態を確認する
- 外出先から状態を確認する
- 水やりの判断材料にする
- 過去の環境変化を確認する
- 通知が来た時だけアプリを開いて詳細を確認する

## 4. 機能要件

画面構成(ホーム / 植物詳細 / 履歴 / 通知・アラート / 設定・植物登録)に対応する形で機能を定義する。

| No | 画面 | 機能 | 説明 |
|---|---|---|---|
| F-01 | ホーム | 植物一覧表示 | 登録植物とその状態をカードで一覧表示 |
| F-02 | ホーム | 今日のまとめ表示 | 平均温度・平均湿度・平均土壌水分を表示 |
| F-03 | 植物詳細 | センサー値表示 | 温度・湿度・土壌水分・照度を表示 |
| F-04 | 履歴 | 履歴グラフ表示 | 過去の環境データをグラフで確認 |
| F-05 | 通知/アラート | 状態悪化通知 | 状態が悪化した植物を通知 |
| F-06 | 通知/アラート | 通知一覧表示 | 過去の通知履歴を確認 |
| F-07 | 設定/植物登録 | デバイス接続 | ESP32デバイスとのペアリング |
| F-08 | 設定/植物登録 | 植物登録 | 植物名・植物種の登録、デバイスとの紐付け |
| F-09 | 設定/植物登録 | 通知設定 | 通知頻度・通知時間帯・通知音の設定 |
| F-10 | 共通 | ESP32通信 | センサーデータをデバイスから取得 |

## 5. 非機能要件

| 項目 | 内容 |
|---|---|
| 応答時間 | 数秒以内に画面へ反映 |
| 通信 | ローカルネットワーク(Wi-Fi) |
| データ保存 | SQLite |
| 対応OS | iOS / Android |
| UI | 初心者でも操作しやすい、情報量を抑えた画面構成 |
| デザイン | デザインシステムに準拠した一貫性のある見た目 |

## 6. デバイス要件(ハードウェア)

| 項目 | 内容 |
|---|---|
| マイコン | ESP32-WROOM-32(Wi-Fi/Bluetooth対応) |
| センサー | BME280(温度・湿度・気圧)、土壌水分センサー(外付け)、照度センサー |
| 電源 | USB-C(5V)またはLiPoバッテリー(3.7V, 約500mAh) |
| 充電管理 | 充電管理IC(TP4056) |
| 通知手段 | フルカラーステータスLED(緑:正常 / 橙:注意 / 赤:エラー) |
| 操作 | リセットスイッチ(Wi-Fi設定リセット用) |
| 動作温度 | 0〜50℃ |
| サイズ | 約35mm × 18mm × 98mm(突起部含まず) |
| 重量 | 約30g |
| 外装 | マットな質感、防滴設計、屋内利用を想定 |

## 7. デザイン要件

- デザインシステム(カラー・タイポグラフィ・コンポーネント)に準拠する
- 基本カラーは Deep Green を基調とし、状態は Success(緑) / Warning(橙) / Error(赤) の3色で表現する
- フォントは Noto Sans JP を使用する
- ボトムナビゲーションは「ホーム / 植物 / 履歴 / 通知 / 設定」の5項目で統一する

詳細は[設計書 7章](system-design.md#7-デザインシステム)を参照。

## 8. 使用環境

| 項目 | 内容 |
|---|---|
| スマホ | iOS / Android |
| ESP32 | Arduino IDE |
| サーバー | Node.js |
| DB | SQLite |

## 9. 制約事項

- ローカルネットワークのみで動作する
- 自動給水は実装しない
- センサーは温度・湿度・土壌水分・照度に対応する
- iOS / Androidの両方を対象とする
- デバイスは1台につき植物1株を想定する
- **認証機能は実装しない(単一ユーザー・単一端末での利用を前提とする)**。アカウント作成・ログイン機能は本バージョンのスコープ外とし、複数端末間でのデータ共有は行わない
