① システム概要

植物の育成環境をセンサーで取得し、スマートフォンアプリから確認できるIoTシステム。

② システムの目的

植物の状態を見える化する
育成をサポートする
センサーデータを記録する
植物の管理を分かりやすくする

③ 利用者

利用者	内容
植物を育てる人	日常的な管理
初心者	育成サポート

④ 利用シーン

朝、植物の状態を確認する
外出先から状態を確認する
水やりの判断材料にする
過去の環境変化を確認する

⑤ 機能要件

No	機能	説明
F-01	ホーム画面	植物一覧と状態を表示
F-02	植物詳細	詳細なセンサーデータを表示
F-03	環境データ表示	温湿度・土壌水分を表示
F-04	履歴表示	過去のデータをグラフで確認
F-05	通知表示	状態悪化を通知
F-06	ESP32通信	センサーデータを取得

⑥ 非機能要件

項目	内容
応答時間	数秒以内に更新
通信	ローカルネットワーク
保存	SQLite
OS	Android
UI	初心者でも操作しやすい

⑦ 使用環境

項目	内容
スマホ	Android
ESP32	Arduino IDE
サーバー	Node.js
DB	SQLite

⑨ 制約事項

ローカルネットワークのみで動作する
自動給水は実装しない
センサーは温湿度・土壌水分のみ対応
Androidを対象とする
