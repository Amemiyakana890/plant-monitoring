1. プロジェクト概要

Plant Environment Monitoring は、植物の育成環境をセンサーで取得し、スマートフォンから状態を確認できるIoTシステムです。
植物の状態を「見える化」することで、育成をサポートすることを目的としています。

2. 制作背景

植物は温度や湿度、水分量などの環境によって生育状態が変化します。
しかし初心者は植物の状態を判断することが難しく、水やりのタイミングや環境の変化に気付きにくいという課題があります。
そこで、環境データをリアルタイムに確認できるシステムを制作し、植物の管理を支援したいと考えました。

3. 課題

課題
植物の状態が分かりにくい
水やりの判断が難しい
過去の環境変化が分からない
初心者は育成に失敗しやすい

4. 解決方法

温湿度や土壌水分をESP32で取得し、Flutterアプリへ送信します。
アプリでは現在の状態だけでなく履歴も確認でき、植物の変化を把握しやすくします。
